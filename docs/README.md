## 📝 文档规范

### 文档命名
- 使用小写字母和连字符
- 例如：`apk-update-system.md`

### 文档结构
```markdown
# 标题

## 概述
简要说明文档内容

## 详细内容
...

## 相关文档
链接到相关文档
```

每个文档底部应包含：
```markdown
---
**最后更新：** YYYY-MM-DD  
**维护者：** 团队名称
```
