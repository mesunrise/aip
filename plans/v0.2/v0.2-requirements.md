# v0.2 版本需求文档

## 版本信息

**版本号：** v0.2  
**版本名称：** 博主定位  
**开发周期：** 预计5-7天  
**依赖版本：** v0.1（通信功能）

## 版本目标

实现自动化的任务需要有task脚本确定。脚本支持抖音App的启动、博主搜索和主页定位功能，为后续的评论采集提供基础。

## 核心功能流程
app点击开始任务后，由服务端向app发送任务指令;
测试开发期间任务指令由tasks/automation-tasks.md定义，后续会根据实际情况制订新的task文档；
支持的指令如下：
- 搜索XXX指令；
- App启动抖音；
- 搜索博主；
- 进入主页；
- 上报结果。

### 详细流程

```
由服务器端根据tasks/automation-tasks.md指令app执行。
```

## 功能需求

### 1. 核心功能

#### 1.1 抖音App启动
**需求描述：**
- 接收云端搜索指令
- 检测抖音是否已安装
