### v0.1：通信验证（Week 1）

**目标：** 建立云端与App的稳定通信

**功能清单：**
- [x] Android App基础框架
- [x] WebSocket客户端实现
- [x] 云端WebSocket服务器
- [x] 心跳保活机制
- [x] 断线重连机制
- [x] 消息收发测试

**技术实现：**

**Android端：**
```kotlin
// 核心功能
1. WebSocket连接管理
2. 消息序列化/反序列化
3. 心跳发送（每30秒）
4. 自动重连（断线后5秒重试）
5. 简单的UI显示连接状态
```

**云端：**
```python
# 核心功能
1. WebSocket服务器（FastAPI）
2. 设备注册和管理
3. 消息路由
4. 连接状态监控
5. 简单的Web控制台
```

**验收标准：**
- ✅ App能成功连接到云端
- ✅ 云端能向App发送消息
- ✅ App能向云端上报状态
- ✅ 断网后能自动重连
- ✅ 心跳正常工作

## 🔄 版本迭代原则

### 1. 小步快跑
- 每个版本1-2周
- 功能单一明确
- 快速验证反馈

### 2. 可验证性
- 每个版本有明确的验收标准
- 可以独立测试
- 有清晰的成功指标

### 3. 向后兼容
- 新版本不破坏旧功能
- 数据库支持迁移
- API保持兼容

### 4. 持续集成
- 每次提交自动构建
- 自动化测试
- 代码质量检查

## 📝 开发规范

### Git工作流

```bash
# 分支策略
main          # 主分支，稳定版本
develop       # 开发分支
feature/v0.x  # 功能分支

# 提交规范
feat: 新功能
fix: 修复bug
docs: 文档更新
refactor: 重构
test: 测试
chore: 构建/工具

# 示例
git commit -m "feat(v0.1): 实现WebSocket客户端"
git commit -m "fix(v0.2): 修复博主搜索失败问题"
```

```

4. 文档更新
```
